# Dashboard dòng tiền gọn cho hộ kinh doanh

Tôi nhận biến file Excel/CSV thu chi thành một dashboard dễ xem trên điện thoại và máy tính.

- Giá mở bán: **299.000đ / dashboard**
- Bản nháp đầu tiên: **trong 48 giờ**
- Phạm vi: 1 dashboard, tối đa 300 dòng dữ liệu, 1 lần chỉnh sửa
- Thanh toán sau khi xem bản nháp
